# 书籍 PDF：目录书签与元信息

## When to Use

- 用户说"把这本书的页码目录 / 书签 / 元信息处理一下"、"这本 PDF 没有目录"、"补个书签"。
- 典型对象是 Calibre 库里的 DuXiu / Anna's Archive 扫描本：纯图像、无文字层、`get_toc()` 为空、metadata 全空。
- 也覆盖**手册/丛书里抽出来的单篇文章**（Elsevier ScienceDirect 章节 PDF：Title 是 `PII: Sxxxx-xxxx(05)xxxxxx-x`，带完整文字层、无书签）。此时元信息写「丛书 + 卷 + 编者 + 起止页 + DOI」，不要当独立成书来写，见 §2。
- 不适用：只需要抽取正文文字（用 `ocr-and-documents`）、或只需要改 PDF 里已有的文字（用 `nano-pdf`）。

产出：完整多层书签（篇/章/节/小节）+ PDF 元信息（书名/作者/出版社/年份/ISBN/语言 + XMP）。

配套脚本：`scripts/pdf_toc_toolkit.py`（inventory / locate / digits / sheet / apply，对应下面流程的每一步）。

## 铁律

1. **不逐页看。** 优先用网络查元信息与目录；PDF 上只精读**目录页**和少量**锚点页**（章节首页、尾部页）。用户明确要求过"不要每页都看"，逐页 vision 浏览是浪费，也是错误做法。
2. **汉字与数字分开取。** tesseract `chi_sim` 读汉字不可靠（大量错字），但读**纯数字列**可靠。所以：标题用视觉精读，页码用数字列 OCR，两者**按行数对齐**交叉验证。
3. **偏移量多点验证。** 印刷页 → PDF 页通常是常数偏移，但必须用 ≥10 个锚点（每章首页 + 参考文献 + 尾部索引）一次性验证，禁止用一页推断全书。
4. **不改印原文。** 原书目录的重号、错字、重复页码、漏条目，照实列给用户，由他决定是否改；书签标题保持书上写法。
5. **写库前备份，写完重开验证。** 覆盖原文件前先复制备份；保存后重开，核对页数、书签条数、若干页仍能渲染（防止图片流被破坏）。
6. **PDF 元信息 ≠ Calibre 的 `metadata.opf`。** 只改 PDF 是本技能的默认范围；是否同步 opf（出版社/ISBN/出版年）要问过用户。
7. **元信息只描述书本身。** 整理者名字、AI 工具名不写进 PDF 字段；`/Creator`、`/Producer` 是工具事实，别伪造。要署名就署在上传说明里，不动文件。扫描来源标记（`DuXiu/SuperStar`、Anna）按用户要求清空；出版社保留为书目事实（引用要用），不当作权属声明。

## 流程

### 1. 盘点

```bash
PYTHONPATH=~/.local/lib/python3.14/site-packages python -c "
import fitz
d=fitz.open('book.pdf'); print(d.page_count, d.metadata); print(len(d.get_toc()))
print([len(d[i].get_text().strip()) for i in range(10)])"
```

文字层长度全为 0 且每页 1 张图 → 扫描本，后续全靠 OCR/视觉。用 `scripts/pdf_toc_toolkit.py` 的 `inventory()`。

### 2. 元信息（网络定书名，版权页才是准的）

搜索 "书名 作者"、"书名 ISBN 出版" 定位书目；百度百科、图书馆书目、豆瓣能给出版社/年份/ISBN。但**别抄它的页数**——百科页数常与实物不符，而版权页通常根本不印页数。

版权页（扫描本里紧跟扉页那一页，"图书在版编目（CIP）数据"块）一次精读就能拿全：书名/著者、ISBN、**中图法分类号**（决定上传站分类）、CIP 核字号、开本、**印张**、字数、印数、定价、版次印次、责任编辑。页数没印时用 `印张 × 16` 估面数，或直接取文件 `page_count`（两者接近就说明扫描本没缺页）。ISBN 再用封底条码核一遍。

**单篇文章（手册的一章）**：不必找版权页，书目事实全在文首那张页上——丛书名（`HANDBOOK OF NUMERICAL ANALYSIS, VOL. II`）、丛书分册名（`Finite Element Methods (Part 1)`）、编者、版权行（`© 1991. Elsevier Science Publishers B.V. (North-Holland)`）。ISBN 与卷次用 Title 里那个 PII 转成 DOI 去 ScienceDirect 核（`S1570-8659(05)80040-7` → `10.1016/S1570-8659(05)80040-7`，同一页给出起止页），别拿二手引用里的页码当准。起止页要能和你算出的印刷页码对上：文章首页 = startingPage、末尾索引页 = endingPage，对不上说明有缺页或算错偏移。XMP 写 `prism:publicationName/volume/isbn/publicationDate/startingPage/endingPage/doi`，Subject 里把丛书卷次与起止页、DOI 一起写全（引用时要用）。

### 3. 目录来源优先级

网络目录 > 书内目录页 > OCR 结果。中文专著在网上常常只公开到"篇"级四行（百科"图书目录"栏就是这样），**不足以做书签**；此时以书内目录页为准，不要拿粗目硬凑。

### 4. 定位目录页（不消耗视觉）

对前 25 页逐页整页 OCR，`re.sub(r'\s+','',text)` 后找 `目录`/`目次`。目录通常紧接在前言之后，页眉是罗马数字（ix…xvii）。确认后只把这些页渲染出来精读：

```bash
python scripts/pdf_toc_toolkit.py locate book.pdf --pages 1-26
```

### 5. 精读目录页

目录页渲染 250 dpi 后逐页问视觉模型"逐行抄录条目文字 + 页码，保留层级"。层级由编号点数决定：`x.y` 是节、`x.y.z` 是小节；`第X篇`/`第X章`/`附录`/`参考文献` 各有固定层级。

同时跑数字列 OCR（右边界 16% 宽度，400 dpi，`--psm 6` + 数字白名单）：

```bash
python scripts/pdf_toc_toolkit.py digits book.pdf --pages 13-21
```

**按行数对齐**：数字个数与标题行数相等才逐行配对；不等就看差在哪（单数字 `3`/`4`/`5` 常被 OCR 整行丢弃，视觉读的单数字可信；两位数字视觉容易把 9 读成 5，OCR 更可信）。个别可疑行再单独放大一次。

### 6. 求偏移量

`PDF 页 = 印刷页 + offset`。做法：把每个候选锚点页（印刷页码 + 假定 offset）的**页首条带拼成一张联系表**，一次视觉全部核对，而不是逐页看：

```bash
python scripts/pdf_toc_toolkit.py sheet book.pdf --anchors 3:24,22:43,71:92 --out /tmp/sheet.png
```

12 章首页 + 参考文献 + 尾部索引全部命中 → 偏移线性成立（中途缺页/重页会让后续锚点整体错位，所以多点覆盖就等于排除了这类问题）。

页眉小字页码**不值得 OCR**：字小、扫描有倾斜，数字列和整页 strip 都会失败，别在这上面耗时间。

### 6.5 清掉 Anna/DuXiu 夹带（书签之后、交付之前）

Anna's Archive 的 DuXiu 扫描本会在 PDF 目录里挂附件名树，常见两条：
`annas_archive_metadata.json.zst`、`original_files.tar.zst`（多为几十字节空壳）。用户通常会要求删掉。

```python
print(d.embfile_count(), d.embfile_names())
for n in d.embfile_names(): d.embfile_del(n)
d.save('/tmp/x.pdf', garbage=4, deflate=True)
```

验证三件事：`embfile_count()==0`；`grep -c -a -i annas file.pdf` 为 0；`qpdf --check` 无语法错误。
删完 `/EmbeddedFiles` 名树会留下空表 `<</Names[]>>`，无害，不必硬抠。

**末页那张 "Document generated by Anna's Archive…" 印章页是页面、不是附件**，删它会改变总页数；
用户只说“删文件”时不要顺手删页，单独问。
用户说“把 Anna 和读秀的都删掉”时，指的是三处一起做：嵌入附件（`embfile_del`）、末页印章页（`d.delete_page(d.page_count-1)`）、
`/Creator` 里的 `DuXiu/SuperStar`（`set_metadata(..., creator='')`，用 `pdfinfo` 复核 Creator 为空）。
三处各自验证，别因为前一步成功就以为整批做完。删页后页码标签要重验（见常见坑）。

DuXiu 的 `/PieceInfo` 里 `000252.pdg` 这类名字是页面件名，不是文件；真要清就一并重建 `/PageLabels`（见 6.6）。

### 6.6 重建页码标签（DuXiu 件名陷阱）

DuXiu 扫描本的 `/PageLabels` 不是真页码，而是**件名表**：数字树每个叶子只有 `/P(cov001.pdg)`、`/P(000253.pdg)`，
所以 Okular/Adobe 的页码框显示 `cov001.pdg`，用户会很难受。必须整棵替换。

这份表还是全页偏移的**独立证据**：正文件名 `000001…000401` 与 `pdf页-21` 逐页对应（402 条里只末页印章页例外）。
收尾时把它抽出来算一遍，等于把书签偏移验证到每一页。

```python
obj = '<</Nums[0<</P()>>4<</S/r>>21<</S/D>>]>>'   # 0-3 无页码；代序起 i；篇名页起 1
x = d.get_new_xref(); d.update_object(x, obj)
d.xref_set_key(d.pdf_catalog(), 'PageLabels', f'{x} 0 R')
```

坑：

- `set_page_labels()` 把非 ASCII 前缀写成 **UTF-8 十六进制串**（`<E5B081E99DA2>`），不是合法的 PDF 文本串，CJK 前缀会坏。
  要 CJK 前缀得手写 `<FEFF` + `s.encode('utf-16-be').hex()`；但 `get_label()` 读不回任何非 ASCII（连 `Ä` 都返回 `<C384>`），
  自己验证不了就别用——给无页码的封面/扉页留**空前缀** `<</P()>>`，或用纯 ASCII 前缀：`/P(C)/S/D/St 1` 得到 C1,C2,C3…（用户偏好这个）。
- 顺手把空掉的 `/Names` 名树设 `null`，`/PageMode` 从 `/UseAttachments` 改成 `/UseOutlines`，
  否则阅读器一打开就弹（已删空的）附件面板。
- **非 DuXiu 的册子也有页码框问题：`/PageLabels` 根本不存在，页码框显示 1..N，而学界引用的是印刷页码。** 别用 `set_page_labels()` 的区间前缀（偏移一分段就表达不了跳跃），直接**逐页显式写 `/Nums`**：
  ```python
  nums = ''.join('%d<</P(%d)>>' % (i, printed_of(i)) for i in range(d.page_count))  # /P 只放数字串
  x = d.get_new_xref(); d.update_object(x, '<</Nums[%s]>>' % nums)
  d.xref_set_key(d.pdf_catalog(), 'PageLabels', '%d 0 R' % x)
  ```
  `printed_of()` 按 §6 求出的偏移分段算。写完用 `d[pg-1].get_label()` 抽查首页/前置页/正文首末页，数字必须等于该页页眉上的印刷页码。

### 7. 写书签 + 元信息

```python
entries = [[level, title, pdf_page], ...]   # level 1..4, pdf_page 从 1 起
doc.set_toc(entries)
doc.set_metadata({'title':..., 'author':..., 'subject':..., 'keywords':..., 'creator':..., 'producer':...})
doc.set_xml_metadata(xmp)   # dc:publisher / prism:isbn / prism:publicationDate
```

- 书签标题去掉 `$` 与 `\,` 等 markdown 数学标记，保留纯文本公式（`V_k^ω(Ω)` 这类可留原样）。
- 中文字符串由 PyMuPDF 自动按 UTF-16 写入 outline，无需额外处理。
- 先备份、存到 `/tmp` 再 `shutil.move` 覆盖原文件，然后**重开验证**。

用 `scripts/pdf_toc_toolkit.py apply` 完成这三步（含备份与验证）。

### 8. 尾部页必须单独核对

印刷目录常漏尾部条目，或末条名称与页内标题不一致。渲染最后 4 页缩略图一次看完：本类书实测遇到过目录写"检索 401"、实际那页标题是"符号索引"，而它前面一页还有一份**未列入目录的总索引**。

### 9. 交付

回复给：元信息表、书签结构与条数统计（各层数量）、页码偏移量及验证方式、**原书目录异常清单**、备份路径；最后一行问是否同步 Calibre `metadata.opf`。不要顺手改 opf。

交付前最后一次清点（四项都要出口径，不能只说“好了”）：`d.page_count` / `len(d.get_toc())` / `d.embfile_count()`；页码标签抽查（首、前置、正文首末）；`qpdf --check` 无语法错误；`grep -a -i` 搜 `duxiu`/`annas`/`superstar` 全为 0。

### 10. 用户要上传（zlib / Anna's Archive）

给一张「栏位 → 值」表，别让用户自己填。分类取中图法分类号对应的站内类目（如 `O242.21` → Mathematics - Computational Mathematics）；系列/卷无则留空；「出版」栏多为出版地，填城市；页数填文件 `page_count`（读者打开看到的就是它），并说明它与印刷末页页码的差别。描述用中文写：书目事实 → 内容简介（版权页那段可直接用）→ 四篇/章结构 → 读者对象 → 版本项 → 这版 PDF 做了什么 → 末尾一行署名。署名写法：`<助理名> 补充整理：目录书签与元信息`，其中 **`<助理名>` 取当前会话里助理对用户自称的名字**（不要写死具体名字，换实例/换人格就对不上）；用户要求不署名就整行不要。**先算字数**对表单上限，不写推销语。这段长文本**只给用户粘到表单里，绝不写进 PDF**（写完 `grep -a` 搜 `内容简介`/`印张` 应为 0）。字段决策表、描述骨架与署名规则见 `references/upload-metadata.md`。

## 常见坑

- **有文字层的 Elsevier/ScienceDirect 单篇章节：不用 OCR，直接读页眉定页码。**
  `get_text("blocks")` 取 `y1 < 0.12*height` 的块就是页眉（`SECTION 12 Local estimates 421` / `436 L.B. Wahlbin CHAPTER III`），
  正则抓 350–525 的整数当印刷页号，一条命令就能得到全书的 `印刷页 → pdf 页` 映射，比 OCR 数字列可靠得多。
  随后用目录页上的印刷页号反查 pdf 页，再核对该页正文首行确实是该节标题，才算验完。
- **偏移量可以是分段的，别假设全书一个常数。** 扫描本会漏掉空白偶数页（章的 verso），
  每漏一页，之后的偏移量就 +1。实测某章：353 段（pdf 1–40）、354 段（pdf 41–135）、355 段（pdf 136–167），
  三个断点正落在两处被丢弃的空白 verso 上。用页眉逐页算偏移，把断点找出来，别用首末两页线性外推。
- **篇名页前后的空白页数并不固定。** 别按"篇名页 + 空白 + 章首页"套模板：实测第一篇是 篇名页/空白，
  第二篇却是 空白/篇名页/空白。判位置用**墨量**（60 dpi 暗像素比例：空白 0.000、篇名页 0.007～0.009、正文 >0.02）
  先筛，再拼一张图确认四页标题，比缩略图凭序猜可靠。
- **chinese OCR 的 `--psm 6` 会整行吞掉单个字符的数字。** 行数不等时不要以为目录漏抄，先把单数字人工补上。
- **不要用整页 chi_sim OCR 抄标题。** 实测错字率高到不可用（"插值"→"撒值"、"空间"→"窒闻"），只可用于定位"目录"这类粗判断。
- **大文件保存用 `garbage=4, deflate=True`，图片流不会被重压缩。** 覆盖后必须验证：`page_count` 不变、`len(get_toc())` 等于预期、若干页低 dpi 渲染的暗像素比例 > 0。
- **目录里连续两条写同一页码是可能的**（印刷如此），不要"修正"成递增。
- **Anna 夹带不止一处**：附件名树里的 `.zst` 才叫嵌入文件；末页印章页、DuXiu `/PieceInfo` 的 `.pdg` 名字都不是，别混为一谈。
- **页码标签与书签是两件事。** 书签跳对页了，页码框里可能还是 `cov001.pdg`，要单独重建 `/PageLabels`。
- **保存后 xref 会变**，拿旧 xref 编号回读会报 `bad xref`；重开后用 `d[pg].get_label()` 抽查即可。
- **删页后页码标签必须重验**：末页标签跟着页数变，删掉印章页后那条多余的编号自然消失；删完 `d[-1].get_label()` 应等于印刷末页页码。
- **搜来源字符串会撞上压缩流的巧合字节**：`grep -a pdg` 能命中图像流里的随机字节（`cQpdg~`、`#pdgS"<`），命中只当线索，看上下文区分件名与噪声；`annas`/`duxiu`/`superstar` 清完后应为 0。
- **XMP 里的 `prism:numberOfPages` 会过时。** 删页（如删印章页）之后它不会自动更新，`pdfinfo` 也不会报；用正则读出来核一遍，改成当前 `page_count`。同理 `dc:date`/`prism:publicationDate` 一旦写过就一直留着。

## 环境注记

- PyMuPDF 可能装在 user site，`import fitz` 失败时加 `PYTHONPATH=~/.local/lib/python3.14/site-packages`。
- 需要 `tesseract` + `chi_sim`：`tesseract --list-langs` 确认；缺则 `pacman -S tesseract tesseract-data-chi_sim`。
- 联系表拼图需要 Pillow。
